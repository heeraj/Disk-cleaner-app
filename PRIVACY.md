# Privacy Policy

**DiskCleaner** is a local desktop / web utility by **Asjau (GTR)**.

## What the app does with data
- Scans and cleans files **only on the machine where you run it**.
- Preferences (theme, schedule reminders) are stored **locally** on your device.
- The app does **not** create accounts, and does **not** upload your files or disk contents to the internet.

## Network use
- In desktop mode the app may start a **local-only** API on `127.0.0.1` so the UI can talk to the cleaner.
- It is not intended to accept connections from other devices on your network.
- No analytics or advertising SDKs are included in this project as shipped.
